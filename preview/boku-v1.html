交互与实现要点

小工具 Tab

卡片式信息流，顺序与显隐由「面板布局」控制。无数据区块（如无动画更新、无翻译任务）整区不渲染，不留空白。后台翻译任务进行中可取消，完成后可点进详情。

翻译 Tab · 对话形态

类似传统翻译 / 聊天：用户气泡（右）+ AI 结果气泡（左）。支持相机 / 相册附件；图片结果可展开为独立详情页（原文 / 译文 / 注音芯片）。底部输入条为毛玻璃胶囊。

快捷指令 / Share

系统 Share Sheet 或快捷指令把「选中文本」或「图片」直接送到翻译页，自动填入并触发翻译。输入条下方有轻提示。可在设置里管理快捷指令说明页。

材质与适配

当前用 backdrop-filter: blur + saturate 模拟液态/磨砂玻璃。真机可用 UIVisualEffectView / SwiftUI .glassEffect（若系统支持）。背景做淡色径向渐变，让玻璃层次可读。

未做剪贴板

按你的要求，iPhone 版小工具暂不包含剪贴板预览与历史；桌面悬浮窗稿中的相关区块可后续按需移植。

设置结构

系统风格分组列表：API Key、划词翻译、阅读 / 房租 / Bangumi / B站、面板布局、通用、关于。二级页用标准 Navigation（返回 + 标题）。
